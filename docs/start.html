After your backup

A green backup can still miss your data.

Compare Docker mount inventory with a restic snapshot listing to find missing paths and stale evidence.

Get source + examplesFull reference

Python 3.11+ · Windows / Linux / macOS · MIT · v0.2.1 · Early release

01

Get ready

Extract the release source.zip. Open a terminal in the folder containing pyproject.toml. Use an isolated environment:

Prepare a Python environment
python -m venv .venv

Windows PowerShell: .venv/Scripts/Activate.ps1. macOS/Linux: source .venv/bin/activate. If activation is unavailable, use .venv/Scripts/python.exe or .venv/bin/python instead of python.

python -m pip install .

Python installation may download dependencies. Checks run locally.

02

See the problem

Synthetic example. A finding is expected here.

python -m backupscope check --inventory examples/inventory.json --snapshot examples/missing.jsonl --policy examples/policy.json --at 2026-09-22T13:00:00Z

The incomplete backup exits 1: documents are missing and a SQL dump is old. The present fixture exits 0. --at fixes time only for these examples.

03

Compare the result

Run the control example and compare the output.

python -m backupscope check --inventory examples/inventory.json --snapshot examples/present.jsonl --policy examples/policy.json --at 2026-09-22T13:00:00Z

Exit 0: this check’s requirements are met.

Bring your own inputs

Review policy.local.json: exact host, backup tags and snapshot paths. Then run verify with --latest and your existing restic configuration. See README for the complete command and HTML output.

python -m backupscope inventory --host YOUR_RESTIC_HOST --output inventory.local.json
python -m backupscope init --inventory inventory.local.json --output policy.local.json

These commands contain example paths: replace them with your own. See the README for input formats and options.

Read the outcome

0 — The check completed without a policy violation.

1 — A concern was found. Review the report and scope.

2 — No complete verdict: check input errors or unsupported constructs.

If you get stuck

File not found: check your working directory. Demo already exists: use a fresh folder for another run. Include the version, command and a sanitized example in an issue.

Report an issue
What the result does not prove

Path presence and freshness are not full coverage, content integrity, database consistency or a successful restore. Keep integrity checks and restore drills.

Examples contain generated data. Review names, paths and host identities before sharing your own reports.

После резервного копирования

Успешная копия может не содержать ваши данные.

Сравните Docker mounts со списком файлов снимка restic: найдите отсутствующие пути и устаревшие данные.

Python 3.11+ · Windows / Linux / macOS · MIT · v0.2.1 · Ранний выпуск

01

Подготовьте запуск

Распакуйте source.zip из релиза. Откройте терминал в папке с pyproject.toml. Установите пакет в отдельное окружение:

Подготовить окружение Python
python -m venv .venv

Windows PowerShell: .venv/Scripts/Activate.ps1. macOS/Linux: source .venv/bin/activate. Если активация недоступна, используйте .venv/Scripts/python.exe или .venv/bin/python вместо python.

python -m pip install .

Установка Python может скачать зависимости. Проверки работают локально.

02

Увидьте проблему

Учебные данные. Ошибка здесь ожидаема.

python -m backupscope check --inventory examples/inventory.json --snapshot examples/missing.jsonl --policy examples/policy.json --at 2026-09-22T13:00:00Z

Неполная копия возвращает 1: нет документов, SQL-дамп старый. Полный пример возвращает 0. --at фиксирует время только для этих примеров.

03

Сравните результат

Запустите контрольный пример и сравните вывод.

python -m backupscope check --inventory examples/inventory.json --snapshot examples/present.jsonl --policy examples/policy.json --at 2026-09-22T13:00:00Z

Код 0: условия этой проверки выполнены.

Перейдите к своим данным

Проверьте policy.local.json: точный host, теги и пути в снимке. Затем выполните verify с --latest и существующей конфигурацией restic. Полная команда и HTML-отчёт — в README.

python -m backupscope inventory --host YOUR_RESTIC_HOST --output inventory.local.json
python -m backupscope init --inventory inventory.local.json --output policy.local.json

Команды содержат примеры путей: замените их своими. Подробности форматов и флагов — в README.

Как читать итог

0 — Проверка завершена, нарушений выбранных условий нет.

1 — Найдена проблема. Изучите отчёт и границы проверки.

2 — Нет полного вывода: проверьте входные данные или неизвестные конструкции.

Если запуск не удался

Файл не найден: проверьте текущую папку. Demo уже существует: выберите новую папку для повторного запуска. Сохраните версию, команду и обезличенный пример для issue.

Сообщить об ошибке
Границы проверки

Наличие путей и свежесть не доказывают полноту, целостность, согласованность БД или успешное восстановление. Сохраните проверки целостности и пробные восстановления.

Примеры не содержат пользовательских данных. Проверяйте имена, пути и host перед публикацией собственных отчётов.
